# project-milestone-3
## Milestone 3: Accessibility & Visual Design

### 1. WAVE Accessibility Fixes
* **Home Page (`index.html`)**: Added missing `alt` attribute to the profile hero image to describe visual content for screen readers.
* **About Page (`about.html`)**: Fixed Footer 
* **Projects Page (`projects.html`)**: Linked explicit `<label>` tags to search filter inputs using matching `for` and `id` attributes.

### 2. Gestalt Principles Applied
* **Proximity**: I used proximity to group my project cards by placing title, description, and tags closely together with smaller margins than the spacing between separate project cards.
* **Similarity**: I used similarity by applying a consistent primary blue background and rounded border radius to all interactive call-to-action buttons across all three pages.
